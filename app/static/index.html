Website & System Architecture

Context Engine uses a dual-engine Grounded RAG architecture designed to process both native digital PDFs and scanned handwritten notes seamlessly.

[PDF Document] ──> [PyMuPDF + RapidOCR Engine] ──> [Recursive Text Splitter]
                                                               │
[LLM Response] <── [BM25 + FAISS Hybrid RRF] <── [384D Vector Embeddings]

Complete System Workflows

  • 1. Document Extraction & OCR: PyMuPDF parses digital text; if text is sparse or image-based, ONNX RapidOCR renders pages at 150 DPI and extracts handwritten text.
  • 2. Hybrid BM25 + FAISS Vector Search: Combines dense vector similarity with BM25 keyword matching using Reciprocal Rank Fusion (RRF) for 100% precision.
  • 3. Page Range & Citation Matching: Direct page range queries (e.g. pages 36 to 54) fetch exact page chunks and label them with source citations.
  • 4. Grounded Synthesis: OpenRouter streaming API synthesizes structured answers backed by exact page references.

Key Production Recommendations

  1. Multi-Column & Table OCR Parsing: Upgrade document processing pipeline to support multi-column layout detection and complex table extraction for scientific papers.
  2. Persistent Cloud Vector Store: Migrate local FAISS files to managed cloud vector databases (e.g. Qdrant, Pinecone) for multi-tenant scalability and low-latency index updates.
  3. Automated RAG Evaluation: Integrate evaluation frameworks (such as RAGAS) to dynamically track precision, recall, and context faithfulness metrics.
